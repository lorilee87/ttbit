# TTBIT

Diário de fé: agradecimentos (TTB), devocional e pedidos de oração.

- Tudo fica guardado só no aparelho de cada pessoa (IndexedDB). Sem login, sem servidor, sem anúncios.
- Funciona sem internet e pode ser instalado na tela de início do celular.
- Cópia de segurança em arquivo, e lembrete diário pelo calendário do celular.
- Português e inglês.

Abrir: https://lorilee87.github.io/ttbit/

## Para quem mexe no código

```
npm install
npm run dev     # ver no computador
npm test        # testes
npm run build   # empacotar
```

Cada push na branch `main` testa e publica no GitHub Pages.
